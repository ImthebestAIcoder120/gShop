# gShop
A new way to install 3ds games right to the tico emulator on your nintendo switch!

originally based on hShop, this lets you download any game and update to the tico/roms/3DS folder on your sd card


# Perquisites

You must have the tico.nro file in switch/tico on your sd card
You must have the azahar 3ds core downloaded and UP TO DATE
You must have a COMPLETE cookie.txt file for internet archive in sdmc/tico

---------------------------------------------------------------------------

# Setting up cookie.txt

Heads up: This app will 99.9999999999999% of the time fail to download with error code 401 or 403 if you do not set up a valid cookie.txt

1. get the chrome extension https://github.com/kairi003/Get-cookies.txt-LOCALLY
2. go into internet archive using this link: https://archive.org/download/xenoblade-chronicles-3-d-korea-en-e-shop-decrypted
3. (important) log in or make an account
4. go back to the archive link
5. press on the chrome extension and press "export"
6. Change the name of the cookie file to just "cookie.txt" (The app wont see the txt file if it isnt spelled right)
7. Move your cookie.txt file to sdmc/tico
8. Download and play your favorite games!
